Native Messaging Host

Opening links in a different browser requires a small helper program (the native messaging host) installed on your system. Follow the steps below.

1
Download the host

Grab browser_switch_host.py and the com.browserswitch.host.json manifest from the native-host/ folder in the repository.

2
Run the installer

Linux / macOS: run install.sh (or install-macos.sh).
Windows: run install-windows.ps1 in PowerShell.

The installer copies the Python script and registers the native messaging manifest so Chrome can find it.

3
Test the connection

About Browser Switch

Browser Switch is an open-source Chromium extension that lets you route links to a different browser (or keep them in the current window) based on URL patterns.

Source code: github.com/renefritze/github-browser-switch
